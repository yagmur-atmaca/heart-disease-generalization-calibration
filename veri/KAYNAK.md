# UCI veri kaynakları ve bütünlük

Bu dosyalar **özgün, sentetik olmayan** UCI veri sürümlerinin GitHub aynalarından alınmış bayt düzeyindeki kopyalarıdır:

- `processed.cleveland.data`: UCI Heart Disease, 303 kayıt, DOI: https://doi.org/10.24432/C52P4X; orijinal https://archive.ics.uci.edu/ml/machine-learning-databases/heart-disease/processed.cleveland.data; ayna https://github.com/tomepedrogit/UCI-Heart-Disease-Dataset/blob/main/processed.cleveland.data ; Git blob SHA1 `97e936c65918c6cda5c1c62661c548ed69afc7b8`.
- `heart.dat`: UCI Statlog (Heart), 270 kayıt, DOI: https://doi.org/10.24432/C57303; orijinal https://archive.ics.uci.edu/ml/machine-learning-databases/statlog/heart/heart.dat ; ayna https://github.com/ymzx/pso-svm/blob/master/data/heart.dat ; Git blob SHA1 `5d17e1692c1eb76ce07da3588852679f6f921a43`.
- `processed.hungarian.data`: UCI Heart Disease, 294 ham kayıt, DOI: https://doi.org/10.24432/C52P4X; orijinal https://archive.ics.uci.edu/ml/machine-learning-databases/heart-disease/processed.hungarian.data; ayna https://github.com/leesael/GSDT/blob/main/data/raw/heart-disease/processed.hungarian.data ; Git blob SHA1 `23b36897a9e72ce2f2fd35edc455630828ca15c8`.

İkili etiketler: Cleveland ve Hungarian için 0→0, 1-4→1; Statlog için 1→0, 2→1. İki verinin bağımsız hasta kimliği kanıtlanmış değildir.
